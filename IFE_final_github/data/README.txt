Data used by the code (run python main.py in the code folder):
  - IFE_term_stock_data.csv : course data (CRSP monthly price and volume)
  - delist_matched.csv      : CRSP delisting returns matched to the course data
  - F-F_Research_Data_Factors_CSV.zip, ff_daily.csv : Ken French RF and daily market returns
  - benchmarks_monthly.csv  : RF, S&P 500 Total Return and SPY monthly returns
  - market_rv_monthly.csv   : monthly market realised variance (layer signal)
The two CRSP files are included in the submission but not uploaded to GitHub (license).
